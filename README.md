# Admission Prediction

This is a simple Machine Learning mini project for predicting whether a student is likely to get admission.

## Features
- GRE Score
- TOEFL Score
- University Rating
- CGPA
- SOP Rating

## Target
- Admission = 1 → Admission Likely
- Admission = 0 → Admission Not Likely

## Algorithm
Logistic Regression

## Files
- app.py
- admission_data.csv
- requirements.txt
- README.md

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Install libraries:
   `pip install -r requirements.txt`
4. Run:
   `python app.py`
